🗂 التخزين

كل preset يُخزَّن في localStorage تحت مفتاح qr_presets كـ JSON array.
كل عنصر فيه: id (uuid) · name · createdAt · settings (كل إعدادات QR) · productIds (اختياري — null لو المستخدم اختار عدم الحفظ).

🔘 زر فتح المودال

زر ثابت في أعلى لوحة الإعدادات اليمنى — نص: "⭐ الإعدادات المحفوظة" + عدد الـ presets الموجودة.
بجانبه زر منفصل: "+ حفظ" يفتح مباشرة dialog الحفظ بدون فتح المودال الكامل.
