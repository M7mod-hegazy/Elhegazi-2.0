## Design Context

### Users
- **Primary Audience:** Store administrators, business owners, and system moderators managing Elhegazi 2.0.
- **Context:** High-intensity usage. Users rely on this platform to manage products, 3D models, categories, user roles, analytics, and global configuration/settings.
- **Job to Be Done:** Need to navigate complex, data-heavy environments quickly, perform bulk actions, and update configurations efficiently without facing cognitive overload.

### Brand Personality
- **Voice/Tone:** Professional, precise, authoritative, hyper-efficient.
- **3-Word Personality:** Avant-Garde, Minimalist, Powerful.
- **Emotional Goals:** Confidence, absolute control, and clarity. The UI should feel exceptionally fast, premium, and "invisible" enough to let the data shine.

### Aesthetic Direction
- **Visual Tone:** Avant-Garde execution with "Intentional Minimalism". 
- **Style:** Absolute rejection of standard, generic bootstrapped layouts. Emphasis on bespoke structures, distinctive typography, and intentional asymmetry where functional.
- **Interactions:** Heavy focus on micro-interactions, perfect spatial alignment, and smooth state transitions.
- **Libraries:** Mandatory discipline in utilizing the existing Shadcn UI / Radix primitive ecosystem. Any complex layout must compose these primitives instead of inventing redundant CSS.
- **Theme & Colors:** High preference for curated, harmonious palettes (including deep, sleek dark modes). Total absence of "default" generic reds/blues/greens.
- **Anti-references:** Bloated or generic Admin Dashboard templates, overly saturated, visually loud, or cluttered interfaces.

### Design Principles
1. **Zero Fluff & Intentional Minimalism:** Eradicate any visual or structural element that lacks an explicit, calculated purpose. Reduction is the highest form of sophistication.
2. **Strict Library Discipline:** Refrain from building core UI components (modals, selects, buttons) from scratch. You MUST use Shadcn UI primitives to guarantee accessibility and code stability, while layering Avant-Garde bespoke styling on top.
3. **Structural & Spatial Hierarchy:** Rely on masterful use of whitespace, typographic scale, and structural alignment instead of aggressive borders, superfluous boxes, or color blocking to separate concerns.
4. **Multi-Dimensional Integrity:** Every layout decision must be evaluated holistically—factoring in WCAG accessibility rules, repaint/reflow optimization, and long-term modularity.
5. **Invisible UX Excellence:** Edge cases (text overflows, async loading states, robust error boundaries) must be actively managed to sustain the illusion of an unbreakable interface.

## Admin Interface Design Context

### Admin Users
- **Primary Users:** Store managers, staff members, business owners
- **Context:** Daily operational use for order processing, inventory management, customer service, and analytics review
- **Job to Be Done:** Efficient data entry, order status updates, product management, user administration, and real-time monitoring
- **Emotional Context:** Professional workspace that feels organized, trustworthy, and empowering—not overwhelming

### Admin Aesthetic
- **Visual Theme:** Consistent with storefront—light, airy surfaces with blue gradient accents
- **Sidebar:** Dark slate (`slate-950`) with gradient overlays for visual contrast and focus
- **Color Palette:**
  - Primary: Blue (`hsl 217 91% 60%` - `#3b82f6`)
  - Secondary: Purple/Indigo variants
  - Success: Emerald (`160 84% 39%`)
  - Warning: Amber (`38 92% 50%`)
  - Destructive: Red (`0 84% 60%`)
  - Background: Light slate gradient (`from-slate-50 via-blue-50/30 to-indigo-50/20`)
- **Typography:** Cairo font (Arabic RTL), gradient text for headings

### Admin Components & Patterns
- **Layout:** Fixed dark sidebar (collapsible) + scrollable content area with header
- **Navigation Groups:**
  - الرئيسية (Dashboard)
  - المبيعات (Orders, Profit)
  - المنتجات (Products, 3D Models, Categories, QR Codes)
  - الإدارة (Users, Locations, History)
  - الإعدادات (Home Config, Settings)
- **Tables:** ModernTable with glass-morphism cards, search/filter/toolbar
- **Stats:** ModernStatCard with gradients, icons, trend indicators
- **Forms:** Clean inputs with focus rings, validation states

### Admin Animations
- **Style:** Keep current vibrant aesthetic—pulse effects, gradient transitions, hover lifts
- **Sidebar:** Smooth 500ms width transitions
- **Cards:** Hover scale/lift effects, subtle shadows
- **Loading:** Skeleton shimmer effects, spinning indicators
- **Charts:** Smooth data transitions, tooltips on hover

### Admin Accessibility (AAA Enhanced)
- **Standard:** WCAG 2.1 AAA compliance
- **Focus States:** Visible focus rings with primary color glow
- **Reduced Motion:** Support `prefers-reduced-motion` media query
- **Contrast:** High contrast ratios for all text (minimum 7:1 for AAA)
- **Touch Targets:** Minimum 44x44px for interactive elements
- **Screen Readers:** Proper ARIA labels, live regions for updates
- **Keyboard Navigation:** Full keyboard accessibility, logical tab order

### Admin Design Principles
1. **Visual Consistency:** Maintain the storefront's light, professional aesthetic throughout all admin pages while ensuring sidebar contrast
2. **Data-First Hierarchy:** Let data drive visual weight—important numbers prominent, secondary info subdued
3. **Action Clarity:** Every action has clear visual affordance; destructive actions are distinctly styled
4. **Responsive Intelligence:** Mobile-first with tablet/desktop enhancements; sidebar collapses gracefully
5. **Performance Perception:** Loading states and transitions maintain feeling of speed even during async operations
6. **Error Recovery:** Clear error messages, undo capabilities, confirmation dialogs for destructive actions
7. **RTL Excellence:** Perfect Arabic RTL support—mirrored layouts, proper text alignment, correct icons

### Admin Anti-Patterns
- Cluttered or busy interfaces that compete with data
- Inconsistent spacing or alignment
- Missing loading/error/empty states
- Non-semantic HTML or improper ARIA usage
- Animations that hinder usability or cause motion sickness
